Wacky Lighthouse

Wacky Lighthouse is a set of public pages that make Lighthouse and PageSpeed Insights return a known result on purpose. Point your tool at one and you know what it should get back: a normal report, a NO_FCP error or a NO_LCP error. Free, no sign-up.

Test pages

  • Valid Response
    Returns a standard, valid Lighthouse response.
  • No FCP
    Returns a NO_FCP runtime error.
  • No LCP
    Returns a NO_LCP error.

How to use it

Run the Lighthouse CLI against a page:

npx lighthouse https://wackylighthouse.com/no-fcp.html --output=json --output-path=report.json

Or the PageSpeed Insights API:

curl "https://www.googleapis.com/pagespeedonline/v5/runPagespeed?url=https://wackylighthouse.com/no-fcp.html"

Then check that your code handles the result: a full report for /, a failed run for /no-fcp.html and a missing LCP for /no-lcp.html.

What the errors mean

NO_FCP

The page never paints anything, so there is no First Contentful Paint. Lighthouse stops the run and puts the error in runtimeError: "The page did not paint any content. Please ensure you keep the browser window in the foreground during the load and try again. (NO_FCP)". Every category score is null. Real sites hit it when the page stays blank, for example a client-side app that fails to render or a page hidden until a script runs.

NO_LCP

The page paints, but nothing it paints counts as a Largest Contentful Paint. The test page draws only a small square on a <canvas>. In Lighthouse 12 the run finishes, the largest-contentful-paint audit carries the error NO_LCP, and the performance score is null while the other categories still score.

Questions

Why would I want Lighthouse to fail?

To test the code around it. Monitoring jobs, CI checks, SEO tools and dashboards that run Lighthouse need to handle failed runs without crashing or reporting a score of zero. These pages give you those failures on demand.

Can I use it in CI?

Yes. The pages are static and public, so any CI job can call them.

Is it free?

Yes. No sign-up, no key, no limits beyond the ones Lighthouse and PageSpeed Insights set themselves.
